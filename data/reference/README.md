# Reference data

## `ekegusii_enchengeria_lexicon.csv`

A derived, structured word-list (5,204 entries: headword, IPA, Swahili gloss + POS,
English gloss + POS) extracted from:

> *Enchengeria – EkeGusii Dictionary: The Complete EkeGusii Trilingual Dictionary*
> (Ekegusii/Kiswahili/English), eds. Prof. John S. Akama, Dr. Evans G. Mecha,
> Dr. Peter N. Otieno, Dr. Peter N. Getenga (Kisii University), published 2023,
> ISBN 9789966082916. Compiled over 14 years from native-speaker lexeme collection —
> see [The Star's coverage](https://www.the-star.co.ke/news/2023-06-05-kisii-dictionary-launched-to-grow-language)
> of the launch, which reported the dictionary was expected to be made freely
> available online.

This file is a **derivative extraction** (headword + gloss + part-of-speech per
entry), not a verbatim reproduction of the published dictionary — it does not
include the full Ekegusii-language definitions, usage notes, or example sentences
that make up the book's actual prose content. It powers the dictionary-prompted
translation mechanism documented in `docs/ekegusii_transfer_learning.md`.

Extracted from an EPUB accessed via personal library-membership access; the
published book itself remains under normal copyright and is not included here.
